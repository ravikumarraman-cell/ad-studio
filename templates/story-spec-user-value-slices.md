# Story Spec: User-Value Slices

Version: 1.0.0

Turn retained intent into the smallest independently valuable user stories.

Rules:
- Use only the retained outcome, acceptance criteria, risk tier, assets, and approved design context.
- One persona, one observable outcome, and one focused Given/When/Then scenario per story.
- Prefer end-to-end user value over UI/API/data-layer tasks.
- State assumptions as open questions; never invent policy, integrations, data, or dependencies.
- Include a failure/recovery story only when retained evidence requires it.

For every story provide: title, `As a / I want / so that` narrative, one scenario, acceptance evidence, explicit non-goals, and unresolved questions.
